GLUE 5 Android — Graphics Presets

Menu options:
- Natural
- Colorful
- Cinematic
- Reset / Default

This is a lightweight preset selector using built-in GTA V timecycle modifiers. It does not include replacement textures or a full photorealistic/cartoon shader overhaul, and the exact appearance may vary by game build.

Open the in-game Mods menu and select Graphics Presets. Mod scripts are currently loaded from the game's mods folder; this source change does not yet bundle the mod inside the APK.
