Vehicle Repair — GLUE 5 Android

Options:
- INSTANT REPAIR: repairs body/deformation, restores engine health, restores driveability and cleans dirt.
- Fix Body & Deformation
- Fix Engine
- Clean Vehicle

How to use:
1. Enable mods or import this mod ZIP through GLUE 5 Studio.
2. Enter the vehicle you want to repair.
3. Open F7 > MENUS (or the in-game MENUS button).
4. Select Vehicle Repair and tap INSTANT REPAIR.

This version repairs the vehicle you are currently in. Repairing every nearby vehicle is not included because the available API support for finding all nearby vehicles has not been confirmed.
Install folder: Android/data/local.glue5/files/mods/Vehicle_Repair/
Keep main.luau and mod.json directly inside the Vehicle_Repair folder.
