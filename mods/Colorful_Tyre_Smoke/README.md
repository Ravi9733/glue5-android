# Colorful Tyre Smoke\n\n- Open the mod menu with F7.\n- Choose White, Red, Blue, Green, Purple, Pink, Yellow, Orange or Cyan.\n- Enable Rainbow to cycle colours.\n- Enable Disable smoke colour to stop the mod applying colours.\n- Supports the current vehicle, including cars and bikes, through GLUE 5 vehicle tyre-smoke natives.\n\nNote: this mod changes smoke colour only. It cannot increase the game's smoke particle density or lifetime.\n
