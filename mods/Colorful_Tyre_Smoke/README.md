# Colorful Tyre Smoke

- Open the mod menu with F7, or use the menu page opened when the mod starts.
- Choose White, Red, Blue, Green, Purple, Pink, Yellow, Orange or Cyan.
- Turn on Rainbow mode to cycle through colours.
- Use Enable smoke colour to turn colour application on or off.
- Press Apply Colour to apply the selected colour to the current car or bike.
- Use Disable Rainbow to stop rainbow cycling.

This mod changes the tyre-smoke colour using GTA V's vehicle native. The game controls smoke density and particle lifetime; this mod does not make the smoke thicker or keep particles alive longer.
