Car Colour Changer — GLUE 5 Android

Features:
- Primary Colour: choose any colour using the colour picker (palette, hue, brightness, hex).
- Secondary Colour: choose any colour for the secondary paint.
- Apply Both Colours: reapplies both selected colours to the current vehicle.
- Random Colours: random primary and secondary paint colours.

How to use:
1. Enable Mods in GLUE 5.
2. Get inside the car you want to repaint.
3. Open F7 > MENUS (or tap MENUS beside Settings).
4. Open Car Colour Changer and choose Primary Colour or Secondary Colour.
5. Pick a colour. The selected paint is applied to the vehicle you are currently driving.

Install folder:
Android/data/local.glue5/files/mods/Car_Colour_Changer/

Keep main.luau and mod.json directly inside Car_Colour_Changer.
This mod changes the current vehicle's custom paint colours; it does not add new paint textures or repaint vehicles you are not sitting in.
