Soft Blur + Colorful — Glue5 Android

The default preset now combines two independent GTA V timecycle effects:
- Primary modifier: hud_def_blur at a subtle 0.14 strength.
- Extra modifier: rply_saturation at 0.30 strength for richer greens and colors.

The menu includes:
- Soft + Colorful (Default)
- Blur: Very Low / Low / Soft (color boost remains active)
- Colors: Natural / Light / Bright (blur remains active)
- Blur OFF (Keep Colors)
- Colors OFF (Keep Blur)
- Reset Graphics

GTA V exposes a primary and an extra timecycle modifier. The extra modifier
allows the colorful saturation effect to run alongside the soft blur instead
of replacing it. If the extra modifier native is not exposed by a particular
game build, the mod log will report that and the primary blur can still work.

Values are intentionally moderate to preserve clear graphics and avoid heavy
post-processing. No FSR or render-resolution reduction is used.
